# Etapa 1 — Definir

**Objetivo:** una ficha de una página que cualquiera entienda. Si no se puede explicar en una página, todavía no se puede construir.

## Pasos

1. Pregunta, de a una: ¿para quién es?, ¿qué problema le resuelve?, ¿cómo lo resuelve hoy esa persona?
2. Pide **una** función principal: la acción que, si funciona, ya hace útil el producto.
3. Recorta. Si aparecen más funciones, van a «Ideas para después». Reglas del primer producto:
   - Un solo tipo de usuario.
   - Una función principal y como máximo tres pantallas.
   - Sin cuentas, pagos ni panel de administración, salvo que la función principal no exista sin ellos.
4. Escribe `producto/ficha.md` con esta forma:

```
# <Nombre>
Para: <quién, concreto: «dueñas de peluquerías de barrio», no «empresas»>
Problema: <qué le duele, en una frase>
Hoy lo resuelve con: <cuaderno, WhatsApp, Excel, nada>
Función principal: <verbo + resultado: «agendar una hora en 3 toques»>
Funciona si: <resultado medible para esa persona>
Persona para validar: <alguien real que lo usaría en la etapa 5>
Fuera del primer producto: <lo recortado>
```

## Listo cuando

- [ ] `[revisas]` `producto/ficha.md` existe y no tiene campos vacíos.
- [ ] `[revisas]` La función principal es una sola acción, sin «y además».
- [ ] `[revisas]` «Para» nombra un grupo concreto, no «todos» ni «empresas».
- [ ] `[evidencia]` Hay una persona real con nombre para la etapa 5.
- [ ] `[decide]` La persona confirma que eso es lo que quiere construir primero.
