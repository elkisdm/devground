# Etapa 5 — Validar con alguien

**Objetivo:** saber si le sirve a una persona real. Que funcione no significa que resuelva el problema.

## Pasos

1. Usa la persona de la ficha (si no está disponible, otra del mismo grupo). Mejor si son 2 o 3.
2. **Prepara la prueba**: el enlace y una sola instrucción con el resultado que buscaría esa persona («agenda una hora para el jueves»). No le expliques cómo se usa.
3. **Observa**: que lo use mientras la ves o comparte pantalla. Anota dónde duda, dónde se traba y qué dice. No la ayudes salvo que se rinda.
4. **Tres preguntas al final**:
   - ¿Pudiste hacer lo que necesitabas?
   - ¿Lo usarías en vez de lo que usas hoy? ¿Por qué?
   - ¿Qué cambiarías primero?
5. Escribe `producto/validacion.md`:

```
# Validación
Persona: <quién, sin datos sensibles> · fecha
Completó la tarea: sí / no / con ayuda
Dónde se trabó: <momentos concretos>
Respuestas: <las tres>
Decisión: seguir / cambiar <qué> / replantear
```

6. **Decide el siguiente paso** con la persona: si se trabó en el recorrido, se arregla eso primero. Si no le resuelve el problema, se vuelve a la etapa 1 con lo aprendido. Si le sirve, se elige la primera idea de «Ideas para después».

## Listo cuando

- [ ] `[evidencia]` Al menos una persona del público lo usó sin ayuda previa.
- [ ] `[revisas]` `producto/validacion.md` tiene sus respuestas y dónde se trabó.
- [ ] `[decide]` Hay una decisión escrita: seguir, cambiar o replantear.

Al cerrar esta etapa, suma 1 a `Vueltas completas` y felicita a la persona: terminó y probó su producto. Pregúntale si quiere otra vuelta guiada, seguir sin guía o quitar todo.
